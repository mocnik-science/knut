The knut language in brief

A query is a list of lines. A line is an output (its result is shown), an assignment name = …, a setting or a define. Commas put several outputs on one line; # starts a comment. A line continues when the next one is indented or a bracket is open.

benches = nodes n with n:amenity=bench   # assignment
count of benches, benches                # two outputs

Names are given once and must be defined before they are used. Spaces matter in three places: n:amenity (tag, no spaces), n:amenity=bench (short form of ==, no spaces) and a = b (assignment, with spaces).

An element is one version of an object. Without a time clause a selection gives the state at the end of the data.

pick KIND x …one element (or none)
pick N KINDS x …a list of up to N; pick exactly N fails with fewer

… ordered by EXPRorder for pick and per chunk (-x for descending)

Time

on DATEstate at that moment
on each month from A to Bstate at the start of every day/week/month/year (time series)
from A to Ball versions (edits, also deletions) in the period
per day|week|month|yeargroup versions by their time
30 days before 2020-01-01shifted dates (after too)

Dates: 2020, 2020-03, 2020-03-07, 7 Mar 2020, Mar 2020, 2020-03-07T14:30Z. A month or year stands for its start, at the end of from … to for its end. All times are UTC.

Units

lengthm km mi mile(s) mil
aream2 km2 mi2 ha
speedkm/h mph knots
times min h days weeks months years
other% (incline), t kg g

A tag value with a unit keeps it ("30 mph"). Otherwise the unit after the key applies (b:height m), else the documented default: maxspeed km/h, height/width/length/ele m, maxweight t, distance km.

History

way A -> way B -> way C [closer than 30 days] with …

Every run of consecutive versions of the same object. closer than limits the time from the first to the last. war_B is the set of the B elements of the matches war; on one match x_B is its B element.

Settings

knut_db = 'file.knutdb'database (relative to the script); the field above the editor overrides it
seed = 42seed for randomly
messages = demessages in German (en is the default)
ignore_warnings = truewarnings found before the run (W003, W005, W006) do not stop it
near_distance = 50 mdistance for near without closer than

Messages

E1xxspelling: spaces, brackets, clause order
E2xxnames, settings, database, places
E3xxdates and units
E4xxthe, pick exactly
E5xxspatial relations and networks
E6xxtypes and values
W001hint while typing: elements without the tag are left out by a comparison (never stops)
W002after the run: the result is empty
W003, W005, W006before the run: a very large region without a filter, a word used as unit and name, a name used as a value

Errors found before running stop the run, and so do the warnings W003, W005 and W006 unless ignore_warnings = true. All of them are underlined in the editor while you type. Errors while running stop it; the results computed so far are kept.
