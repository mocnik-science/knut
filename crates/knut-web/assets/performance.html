Performance

Scaling how the time grows with the size of the input

Each series runs the same program on growing inputs. The time is fitted as overhead + b·sizek, the overhead being the time of the smallest input (parsing, finding the place, …): k ≈ 1 is linear, below is sublinear (indexes, boxes), above is superlinear. The dashed line is what linear growth with the same overhead would give, through the largest input; “local k” is the slope between neighbouring inputs.
